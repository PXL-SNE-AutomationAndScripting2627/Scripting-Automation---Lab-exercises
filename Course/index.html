Course overview

Learn to use PowerShell to solve IT administration tasks and automate recurring work. The course starts with PowerShell Basics, then applies those skills in PowerShell Automation.

Topics

PowerShell Basics

  • Commands and help; objects, processes, services, and pipelines.
  • Filtering, sorting, grouping, measuring, and regular expressions.
  • Output, formatting, files, and directories.
  • Variables, data types, calculations, and parameters.
  • Conditionals, loops, error handling, functions, and modules.

PowerShell Automation

  • Local user accounts and Windows information.
  • Windows management and Active Directory.
  • Remote access, networking, and the registry.

Study method

Work through each topic using the course, hands-on exercises, and labo assignments together.

  1. Course — understand the concepts. Read the lesson and run its small examples. Predict the results, inspect the output, and explain what happened. Answer the questions before opening Show solution.
  2. Hands-on — practise the skills. Complete the matching hands-on exercises. Start with the guided activities, then attempt the independent challenge. Check the solutions after trying, and use the lesson as a reference when you need an explanation.
  3. Labo assignments — apply the skills independently. Open the separate assignment repository through the link in Blackboard. Read the task, combine the relevant course concepts, and develop your own solution. Follow the assignment requirements and the submission instructions in Blackboard.

The lesson and its hands-on form one learning unit: the lesson explains the concepts, and the hands-on helps you apply them. Use the labo assignments to show that you can choose and combine those skills for a new problem. Review mistakes and revisit the relevant explanation before moving to the next topic.
