08 - Arithmetic calculations

Originele pagina openen →

Learning objectives

  • Apply arithmetic operators in PowerShell expressions.
  • Predict how numeric and string types affect calculations.
  • Read user input and cast it safely.

Prerequisites

  • Understand variables and basic data types.

Reference: about_Arithmetic_Operators

Casting

From input to calculation

flowchart LR
    A["Read-Host: text input"] --> B["Validate and convert to a number"]
    B --> C["Perform numeric arithmetic"]
    C --> D["Round or format the result when needed"]

Invalid numeric input must be reported or corrected rather than used as a number. Casting changes the type; formatting is for presentation.

#Example: you need to read in a number that will be multiplied by 10

$number = Read-Host "Enter a number"
$number = $number * 10
$number
$number.GetType().Name

#Declare as integer [casting]
[int]$number = Read-Host "Enter a number"
$number = $number * 10
$number
$number.GetType().Name

#Declare as a string
[string]$city = Read-Host "Where do you live?"
$city = $city * 10
$city
$city.GetType().Name
