Cmdlets, Get-Help, Get-Command, Get-Member, Get-Alias

01 - Cmdlets, help, and commands

Originele pagina openen →

Learning objectives

  • Recognise PowerShell's verb-noun cmdlet convention.
  • Discover commands and retrieve syntax, examples, and parameter help.
  • Use Get-Member and aliases appropriately.

Prerequisites

  • Complete the introduction and have an interactive PowerShell prompt available.

Cmdlets

A Cmdlet -- pronounced command-let -- is a small, lightweight command that is used in the Windows PowerShell environment.

Cmdlets use a verb-noun naming convention; aliases, functions, scripts, and external applications do not necessarily follow it.

Example: Get-Help, Get-Command,Get-Member,Get-Process, ...

Command discovery overview

flowchart LR
    A["Find a command: Get-Command"] --> B["Learn its parameters: Get-Help"]
    B --> C["Run a safe query"]
    C --> D["Inspect its objects: Get-Member"]

Use the help and examples to check a command before running it, especially when it can change data.

Overview of all verbs:

Get-Verb

The -Group parameter for the Get-Verb cmdlet allows you to filter the list of approved verbs by a specific group. The "Common" group is one of the predefined groups that you can use to filter the list of verbs.

Get-Verb -Group Common
Get-Verb -Group security

Update help documentation

  • Update-Help checks the version of the help files on your computer.
  • Update PowerShell Help after installing PowerShell and periodically thereafter
  • Run Update-Help in an elevated PowerShell session when required, then restart PowerShell if prompted.
  • Some help files are not translated to a specific language.
Update-Help -Verbose -UICulture en-US -force

Get-Help

  • Displays information about PowerShell commands and concepts.
  • It is a valuable command for accessing documentation about cmdlets, functions, modules, scripts, and PowerShell concepts.
  • It helps you understand command syntax, parameters, and examples.
  • Dumps everything at one go, you can use | more to view page by page.
  • Shows the MAML(Microsoft Assistance Markup Language) or Comment-Based help written by the module author.
Get-Command Get-Help -Syntax

Get-Help [[-Name] <string>] [-Path <string>] [-Category <string[]>] [-Full] [-Component <string[]>] [-Functionality <string[]>] [-Role <string[]>] [<CommonParameters>]
Get-Help [[-Name] <string>] -Detailed [-Path <string>] [-Category <string[]>] [-Component <string[]>] [-Functionality <string[]>] [-Role <string[]>] [<CommonParameters>]
Get-Help [[-Name] <string>] -Examples [-Path <string>] [-Category <string[]>] [-Component <string[]>] [-Functionality <string[]>] [-Role <string[]>] [<CommonParameters>]
Get-Help [[-Name] <string>] -Parameter <string[]> [-Path <string>] [-Category <string[]>] [-Component <string[]>] [-Functionality <string[]>] [-Role <string[]>] [<CommonParameters>]
Get-Help [[-Name] <string>] -Online [-Path <string>] [-Category <string[]>] [-Component <string[]>] [-Functionality <string[]>] [-Role <string[]>] [<CommonParameters>]
Get-Help [[-Name] <string>] -ShowWindow [-Path <string>] [-Category <string[]>] [-Component <string[]>] [-Functionality <string[]>] [-Role <string[]>] [<CommonParameters>]

Parameters:

  • Name: Specifies the name of the cmdlet, function, script, module, or topic for which you want to get help.

  • Parameter: Allows you to specify a specific parameter within the cmdlet or function for more detailed help.

  • Category: Filters the help content based on specific categories like "Cmdlet," "Function," "Script," and more.

  • Full: Retrieves the full help content, including examples and detailed descriptions.

  • Online: Opens the online version of the help content in your default web browser.

  • ShowWindow: Opens a separate help window.

  • Examples: Displays examples of how to use the cmdlet or function.

  • If you want to learn more about a command, you can always get help on it.

Examples:

Get-Help Get-Command 
# or
Help Get-Command
# or
Get-Command -?
  • For information
Get-Process -?
Get-Help Get-Process
Help Get-Process
  • Only show examples
Get-Help Get-Process -Examples
  • For more information
 Get-Help Get-Process -Detailed
  • For technical information
 Get-Help Get-Process -Full
  • For online help
 Get-Help Get-Process -Online
  • Display help information in UI Window
Get-Help Get-Process -ShowWindow

PowerShell Online Help

Global help files about general topics:

In PowerShell, global help files, often referred to as "about_ topics," provide valuable information about various aspects of PowerShell and its usage. These topics are available through the Get-Help cmdlet and can be accessed to learn more about PowerShell itself, its concepts, and best practices. Here are some common global help topics in PowerShell:

  • about_Automatic_Variables: This topic explains the automatic variables in PowerShell, which are predefined variables that store system information or user-defined preferences.

  • about_Comment_Based_Help: It provides information on how to add comments to your scripts and functions to provide inline help.

  • about_Execution_Policies: This topic explains PowerShell execution policies and how they affect script execution.

  • about_Functions: It covers creating and using functions in PowerShell.

  • about_Pipelines: It explains how pipelines work in PowerShell and how to pass data between cmdlets using the pipeline operator (|).

  • about_Scripts: It provides information on writing and running scripts in PowerShell.

  • about_Variables: It explains how to work with variables in PowerShell, including variable scope and naming conventions.

To access information on any of these topics or others, you can use the Get-Help cmdlet followed by the specific topic name. For example, to get help on automatic variables, you can use the following command:

Get-Help variables

Name                              Category  Module                    Synopsis
----                              --------  ------                    --------
Set-DynamicParameterVariables     Function  Pester                    …
about_Automatic_Variables         HelpFile
about_Environment_Variables       HelpFile
about_Preference_Variables        HelpFile
about_Remote_Variables            HelpFile
about_Variables                   HelpFile

Get-Help about_variables

Get-Help about_variables -online

Get-Help: The online version of this Help topic cannot be displayed because the Internet address (URI) of the Help topic is not specified in the command code or in the help file for the command.

Online Help for PowerShell topics can be found at the following link:

  • PowerShell Documentation

Wildcard support:

The Get-Help cmdlet, by default, performs wildcard searches when you provide a partial or incomplete cmdlet or help topic name. However, you can make it perform an exact match search without using wildcards by providing the complete cmdlet or topic name enclosed in double quotes.

Get-Help execution_pol

Get-Help about*var*

Get-Help about_Variables

Get help of a specific parameter of a Cmdlet:

Get-Help Get-Command -Parameter all

Get-Help Get-Process -Parameter id

Get-Command

This command gets the PowerShell cmdlets, functions, and aliases that are installed on the computer.

Get-Command

This command gets all commands of all types on the local computer, including executable files in the paths of the Path environment variable ($env:path).

Get-Command *

Is there a difference between the two commands?

Show solution

Yes. Without a name or pattern, Get-Command lists aliases, functions, and cmdlets. Supplying * also searches for external scripts and applications available through $env:PATH. Available module commands can be discovered without the module already being imported. The exact results depend on installed commands and the current environment.

Get-Command Notepad

-----------     ----                                               -------    ------

Wildcards:

Get-Command uses the exact name of the command, without wildcard characters you have type the full command.

Get-Command -name service

Get-Command: The term 'service' is not recognized as a name of a cmdlet, function, script file, or executable program.
Check the spelling of the name, or if a path was included, verify that the path is correct and try again.

With the use of wildcards, all possible Cmdlets will be shown.

Get-Command -name *service

...
Cmdlet          Get-Service                                        7.0.0.0    Microsoft.PowerShell.Management
...

Searching for just a verb or noun:

Get-Command -verb get -noun process

Show syntax of a command:

 Get-Command Get-Process -Syntax

Get-Process [[-Name] <string[]>] [-Module] [-FileVersionInfo] [<CommonParameters>]
...

Syntax is vital for several important reasons:

  • Correct Interpretation: Syntax defines the structure and rules for writing PowerShell code. Following proper syntax ensures that PowerShell can correctly interpret and execute your commands. Incorrect syntax can lead to errors and unexpected behavior.

    • The -Name parameter is optional; when a name is supplied positionally, it is the default parameter for Get-Process.

  • Readability: A well-structured and consistent syntax makes your code more readable and understandable. It helps both you and others who may read or collaborate on your scripts. Clear code is easier to maintain and troubleshoot.

  • Consistency: PowerShell has a well-defined syntax, including rules for naming conventions, parameter order, and command formatting. Adhering to these conventions ensures consistency across scripts and modules, making your codebase more cohesive and maintainable.

  • Preventing Errors: Proper syntax helps prevent syntax errors, which can disrupt script execution. PowerShell's strict syntax checking is designed to catch and highlight syntax errors early, which can save you time and effort during debugging.

  • Avoiding Ambiguity: Accurate syntax helps PowerShell avoid ambiguity in command interpretation. When you write code that follows the expected syntax, PowerShell can confidently identify the intended action and execute it correctly.

  • Predictability: Correct syntax allows you to predict the behavior of your code more reliably. It ensures that your scripts execute as you intended and produces the expected outcomes.

  • Compliance with Best Practices: PowerShell has best practices and guidelines for naming, formatting, and structuring your code. Adhering to these best practices ensures that your code is consistent with industry standards and facilitates collaboration with other PowerShell users.

  • Integration with Ecosystem: Proper syntax is essential for integrating PowerShell with other systems, tools, and services. Interoperability often relies on adhering to a specific syntax for command invocation and parameter passing.

  • Security: Misused or improperly formatted commands can be a security risk. Ensuring correct syntax helps reduce the likelihood of security vulnerabilities in your scripts.

  • Documentation and Help: Well-structured syntax is critical for generating and understanding code documentation and help content. It helps others, including future maintainers and users of your scripts, to find and utilize the correct commands and parameters.

Get-Member

The Get-Member cmdlet in PowerShell is a powerful and useful tool for understanding and exploring objects and their properties and methods. It's a valuable asset when programming in PowerShell for several reasons:

  • Object Inspection: Get-Member allows you to inspect the structure and characteristics of objects. This is especially useful when dealing with unfamiliar objects or when you need to understand what properties and methods are available.
Get-Process | Get-Member
  • Property Discovery: You can use Get-Member to discover the properties of an object. Knowing an object's properties is essential for accessing and manipulating its data.
Get-Process | Get-Member -MemberType Property
  • Method Exploration: It helps you explore the methods associated with an object. Methods are actions or functions that you can invoke on an object. Get-Member lets you discover what actions are available.
Get-Process | Get-Member -MemberType Method
  • Type Identification: You can use Get-Member to determine the data type of an object. Knowing the data type is crucial for performing data type-specific operations.
Get-Process | Get-Member |
    Select-Object -ExpandProperty TypeName -Unique
  • Dot-Notation Exploration: It guides you in using dot notation to access properties and methods of objects. For example, if you want to access a property or invoke a method, you'll often use the dot notation, and Get-Member helps you identify the available options.
 (Get-Process smss).Id

  • Object Hierarchy: When dealing with complex objects or object hierarchies, Get-Member assists in navigating and understanding the structure. This is particularly useful for objects that contain other objects or collections.

  • Debugging and Troubleshooting: Get-Member is an invaluable tool for debugging and troubleshooting. It can help you identify issues related to object properties and methods that might be causing errors or unexpected behavior in your scripts.

  • Learning and Exploring APIs: When working with external APIs, web services, or modules, Get-Member helps you explore the available functionality, enabling you to make effective use of those APIs in your scripts.

  • Documentation and Self-Discovery: Get-Member can serve as a form of self-documentation. When you're working with objects, you can use Get-Member to quickly understand what's possible without having to consult external documentation.

  • Scripting and Automation: It facilitates scripting and automation by allowing you to dynamically discover and interact with the properties and methods of objects, making your scripts more versatile and adaptable to various scenarios.

Get-Alias

Alias Exploration: It allows you to explore and list the aliases defined in your PowerShell session. This is helpful when you want to know what shorthand notations are available for common cmdlets and functions.

Get-Alias

Quick Command Entry: Aliases provide a convenient way to quickly enter common cmdlets or functions. For example, ls and dir are aliases for Get-ChildItem.

Get-Alias ls

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           ls -> Get-ChildItem

Reducing Typing: Aliases can significantly reduce the amount of typing needed to execute commands, which can be especially helpful for long or frequently used commands.

  • Alias ps -> Get-Process

Learning and Transitioning: For users who are new to PowerShell or transitioning from other shell environments, Get-Alias can be a valuable resource for quickly identifying the aliases for familiar commands.

Interactive Use: When working interactively in the PowerShell console, you can use aliases for rapid testing and command execution.

Script Readability: While aliases can be useful for command entry, it's often recommended to use full cmdlet names in scripts to improve script readability and maintainability.

Parameter -definition:

Gets the aliases for the specified item. Enter the name of a cmdlet, function, script, file, or executable file.

Get-alias -Definition Get-Process

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           gps -> Get-Process
Alias           ps -> Get-Process
