What are loops?

Select an image to open it at full size. Close the image tab or use Back to return to the lesson.

In PowerShell, loops are control structures that allow you to repeatedly execute a block of code as long as a certain condition is true or for a specified number of iterations. PowerShell provides several types of loops, including:

  • For Loop: The for loop is used to iterate a specific number of times. It has a counter variable that is initialized, tested for a condition, and incremented or decremented in each iteration.
for ($i=1; $i -le 5; $i++) {
    Write-Host "Iteration $i"
}
  • While Loop: The while loop executes a block of code as long as a specified condition is true.
$counter = 1
while ($counter -le 5) {
    Write-Host "Iteration $counter"
    $counter++
}
  • Do-While Loop: Similar to the while loop, but it tests the condition after executing the block of code, ensuring that the block of code is executed at least once.
$counter = 1
do {
    Write-Host "Iteration $counter"
    $counter++
} while ($counter -le 5)
  • ForEach-Object Loop: The ForEach-Object cmdlet is often used in a pipeline to iterate over a collection of items.
1..5 | ForEach-Object {
    Write-Host "Iteration $_"
}

In this example, 1..5 creates an array of numbers from 1 to 5, and ForEach-Object processes each number in the pipeline.

  • Foreach Loop: The foreach loop is used to iterate over elements in an array or collection.
$numbers = 1, 2, 3, 4, 5
foreach ($number in $numbers) {
    Write-Host "Number: $number"
}

These loop constructs provide flexibility in controlling the flow of your PowerShell scripts, allowing you to repeat a set of instructions based on specific conditions or for a defined number of iterations.

For Loop

Get-Help about_for

Syntax:

for (<initializer>; <condition>; <iterator>) {
    # Code to be executed in each iteration
}
  • Initializer: Initializes a counter variable or any variable that controls the loop.
  • Condition: Specifies the condition that must be true for the loop to continue executing.
  • Iterator: Defines how the counter variable is updated after each iteration.

Example:

for ($i = 1; $i -le 5; $i++) {
    Write-Host "Iteration $i"
}

Output:

Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5

Explanation:

  • Initializer ($i = 1): Initializes the counter variable $i to 1 before the loop starts.
  • Condition ($i -le 5): Specifies that the loop should continue as long as the value of $i is less than or equal to 5.
  • Iterator ($i++): Increments the value of $i by 1 after each iteration.
  • Code Block: The block of code inside the curly braces is executed in each iteration of the loop. In this case, it prints the current iteration number using Write-Host.

In each iteration, the counter variable $i is incremented, and the loop continues until the condition ($i -le 5) becomes false.

Example 1 - for_loop_01.ps1:

for ($i = 1; $i -lt 5; $i++) {
    Write-Output "Sleeping for $i seconds"
    Start-Sleep -Seconds $i
}

Example 2 - :

$fruit = @('apple','pear','banana','lemon','lime','mango')
# -le means less or equal to
For ($i = 0; $i -le $fruit.length; $i++) {
    Write-Host $fruit[$i];    
}

While Loop

about_While

Syntax:

while (<condition>) {
# Code to be executed as long as the condition is true
}

Example:

$counter = 1
while ($counter -le 5) {
    Write-Host "Iteration $counter"
    $counter++
}

Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5

Explanation:

  • Initialization ($counter = 1): Initializes a counter variable $counter to 1 before the loop starts.
  • Condition ($counter -le 5): Specifies that the loop should continue as long as the value of $counter is less than or equal to 5.
  • Code Block: The block of code inside the curly braces is executed as long as the condition is true. In this case, it prints the current iteration number using Write-Host and increments the counter variable.
  • Increment ($counter++): Increments the value of $counter by 1 after each iteration.

In each iteration, the condition ($counter -le 5) is checked. As long as the condition is true, the code block is executed, and the counter is incremented. The loop continues until the condition becomes false.

Do-While Loop

Compare when the condition is checked

flowchart LR
    A["while: check condition"] --> B["Run body if true"]
    C["do-while: run body first"] --> D["Check condition to continue"]

The while body can run zero times; the do-while body runs at least once. Both loops repeat until their continuation condition is false.

about_While

A Do-While loop is a variant of the While loop, and the main difference is that the script block is executed before the condition is checked. This means that even if the start condition is false, the script block will be executed at least once.

$counter = 1
do {
    Write-Host "Iteration $counter"
    $counter++
} while ($counter -le 5)

Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5
  • Initialization ($counter = 1): Initializes a counter variable $counter to 1 before the loop starts.
  • Code Block: The block of code inside the curly braces is executed at least once. In this case, it prints the current iteration number using Write-Host and increments the counter variable.
  • Increment ($counter++): Increments the value of $counter by 1 after each iteration.
  • Condition ($counter -le 5): After the code block is executed, the condition is checked. If the condition is true, the loop continues; otherwise, it exits.

In this example, the loop executes the code block at least once, even if the condition ($counter -le 5) is false initially. This can be useful when you want to ensure that a certain piece of code runs before checking the exit condition.

Example:

$i = 15;
Do {
    Write-host "Do While $i is less then 15";
    $i++;
}
While ($i -lt 10)

$i = 15;
while ($i -lt 10) {
    Write-host "While $i is less then 15";
    $i++;
}

Do-Until Loop

Do Until is pretty much the same as Do While in PowerShell. The only difference is the condition where they run on.

  • Do While keeps running as long as the condition is true. When the condition is false it will stop.
  • Do Until keeps running as long as the condition is false. When the condition becomes true it will stop.

Example:

Do {
    Write-Host "Computer offline"
    Start-Sleep 5
}
Until (Test-Connection -ComputerName 'LaptopPXL' -Quiet -Count 1)
Write-Host "Computer online"

Example:

do {
        $notepad = Get-Process Notepad -ErrorAction SilentlyContinue
        Start-Process Notepad.exe
        Write-Host "Starting Notepad, current count is: $($notepad.Count + 1)"
        $notepad = Get-Process Notepad
   } until ($notepad.Count -eq 5)

ForEach loop

about_Foreach

Syntax:

foreach ($item in $collection) {
    # Code to be executed for each $item in $collection
}

Example:

$numbers = @(1, 2, 3, 4, 5)
foreach ($number in $numbers) {
    Write-Host "Number: $number"
}

Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
  • Array Initialization ($numbers = 1, 2, 3, 4, 5): Initializes an array of numbers.
  • foreach Loop Syntax: The loop iterates over each element in the $numbers array.
  • Variable ($number): The variable $number is used to represent each element of the array in each iteration.
  • Code Block: The block of code inside the curly braces is executed for each element in the array. In this case, it prints the current number using Write-Host.

Example:

$ComputerNamen = 'WinServer01', 'WinClient-01', 'WinClient-02', 'WinClient-03'
$Teller = 1
foreach ($ComputerNaam in $ComputerNamen) {
    Write-Output "Computernaam $Teller`: $ComputerNaam"
    $Teller = $Teller + 1
}

Computernaam 1: WinServer01
Computernaam 2: WinClient-01
Computernaam 3: WinClient-02
Computernaam 4: WinClient-03

ForEach-Object Loop

Syntax:

<collection> | ForEach-Object {
    # Script block to be executed for each item in the collection
    # $_ represents the current item in the iteration
}

ForEach-Object cmdlet that can be used in a pipeline to iterate over a collection:

1..5 | ForEach-Object {
    Write-Host "Number: $_"
}

1..5 creates an array of numbers from 1 to 5, and ForEach-Object processes each number in the pipeline. The $_ represents the current object in the pipeline.

example:

$numbers = 1, 2, 3, 4, 5

$numbers | ForEach-Object {
    $doubled = $_ * 2
    Write-Host "Original: $_, Doubled: $doubled"
}

example:

Get-Content -Path C:\tmp\subdomains.txt | ForEach-Object {
    Write-Host "Processing line: $_"
    # Add your processing logic here
}

ForEach and %

ForEach-Object has two shorthands that you can use, ForEach and %. The place where you use ForEach determines which version of the two is used.

$fruits = @('apple', 'pear', 'banana', 'lemon', 'lime', 'mango')
# Foreach - Loads all the fruits in the memory and process it
# Takes 21,4553 miliseconds
Foreach ($fruit in $fruits) {
    Write-Host $fruit;
}

#Shorthand for foreach
# Takes 14,3926 miliseconds
$fruits.foreach( {
        Write-Host $_;
}) 

# ForEach-Object 
# Takes 7,8812 miliseconds
$fruits | ForEach-Object { Write-Host $_ }

# Shorthand for ForEach-Object
# Takes 7.3507 miliseconds
$fruits | ForEach { Write-Host $_ }

# Also a Shorthand for ForEach-Object
# Takes 7,2982 miliseconds
$fruits | % { Write-Host $_ }

Foreach faster

If we take a large data set, with 300.000 records for example, then we can see that foreach can be a lot faster than ForEach-Object. Only the memory consumption would be a bit higher of foreach.

$items = 0..300000
# Takes 180 ms to complete
(Measure-Command { foreach ($i in $items) { $i } }).TotalMilliseconds
# Takes 1300 ms to complete
(Measure-Command { $items | ForEach-Object { $_ } }).TotalMilliseconds
# Takes 850 ms to complete
(Measure-Command { $items.ForEach({ $i })}).TotalMilliseconds

ForEach-Object Script Blocks

ForEach-Object allows you to use script blocks which can be really useful when you need to log the process or clean up when the script is completed.

$path = "C:\temp"
$totalSize = 0

Get-ChildItem $path | ForEach-Object -Begin {
    Write-Host "Processing folder $path"
} -Process {
    $totalSize += ($_.length / 1kb)
} -End {
    Write-host $totalSize "Kb"
}

Break, continue statements

Break and continue are control-flow statements used within loops to alter the normal flow of execution.

break Statement

The break statement is used to exit a loop prematurely. When encountered, it immediately terminates the loop, and the program control moves to the next statement after the loop.

$numbers = 1..10

foreach ($number in $numbers) {
    if ($number -eq 5) {
        Write-Host "Breaking at $number"
        break
    }
    Write-Host "Current number: $number"
}
Write-Host "Loop finished"

Current number: 1
Current number: 2
Current number: 3
Current number: 4
Breaking at 5

continue Statement

The continue statement is used to skip the rest of the code inside a loop for the current iteration and move on to the next iteration.

for ($i = 1; $i -le 5; $i++) {
    if ($i -eq 3) {
        Write-Host "Skipping iteration $i"
        continue
    }
    Write-Host "Processing iteration $i"
}
Write-Host "Loop finished"

Processing iteration 1
Processing iteration 2
Skipping iteration 3
Processing iteration 4
Processing iteration 5
Loop finished

$Users = Import-Csv -LiteralPath '.\users_small.csv' -Delimiter ';'
$Users

The supplied file is semicolon-delimited. Each data row becomes an object with GivenName and Surname string properties. Using the default comma delimiter would treat the semicolon-separated header as one property.

$Users | Get-Member -MemberType NoteProperty

The supplied CSV's field names become GivenName and Surname properties. The CSV's first line supplies those names; subsequent rows supply their values. If only one combined header appears, check -Delimiter ';'.

  • Specify a separator other than comma
Show solution 
$users = Import-Csv -LiteralPath '.\users_small.csv' -Delimiter ';'
foreach ($user in $users) {
    $givenName = $user.GivenName
    $surname = $user.Surname
    Write-Output ('{0} has surname {1}' -f $givenName, $surname)

-Delimiter ';' matches the supplied file. Each iteration handles one row. For example, the row for Alex Janssens produces Alex has surname Janssens. A different file needs its own actual separator; changing the parameter does not rewrite the file.
