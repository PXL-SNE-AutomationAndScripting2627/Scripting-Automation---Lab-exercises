Course tracks <!--

The course has two sequential tracks:

  1. PowerShell Basics develops object, pipeline, scripting, error-handling, function, and module skills.
  2. PowerShell Automation applies those skills to Windows local accounts, system information, management, Active Directory, remoting, networking, and the registry.

Complete PowerShell Basics before starting PowerShell Automation. Automation hands-on exercises require assigned Windows or Windows Server lab environments; never substitute a production computer.

Use the hands-on sequence alongside the lessons. Lab 04b — Files and directories follows the combined output lab 04 and precedes regex lab 05. This insertion preserves all existing lab numbers. Each lab's prerequisites link to the lesson or lessons to complete first.

Lesson template <!--

Every lesson follows the same study cycle:

  1. Learning objectives — capabilities to demonstrate after studying.
  2. Prerequisites — prior knowledge and tools to have ready.
  3. Core material and demonstrations — concepts and annotated examples.
  4. Practice and self-check — apply concepts before proceeding; use the linked formative checks and hands-on exercises.
  5. Summary — commands and ideas to retain, consolidated in the formative-check material.

Complete each lesson and lab in order. Run examples in the specified practice environment, adapt only instructor-approved names and paths, and use Get-Help <command> -Examples whenever an example is unclear.
