Hands-on — Output, formatting, files, and directories

04 - Output, formatting, files, and directories

Originele pagina openen →

Goal

Prepare a device-returns handover for a school lending desk: organise input records, preserve an evidence copy, and produce reports for people and scripts.

Learning objectives

After completing all parts, you can:

  • choose literal or expandable strings for a task;
  • distinguish success-output objects, host messages, and formatting records;
  • organise and inspect a dedicated practice workspace;
  • select log files and find relevant records without matching unrelated notes;
  • preview, copy, move, rename, and verify an evidence file; and
  • export and import CSV, JSON, and CLIXML and produce a separate text report.

Advanced Activities 6.2 and 6.3 compare JSON and CLIXML with CSV. All activities are required; advanced identifies greater depth.

Prerequisites

  • PowerShell 7 on Windows and Visual Studio Code or Windows Terminal.
  • Basic pipelines, properties, filtering, and sorting.
  • Complete the Files and directories lesson and the output, formatting, and export lesson before starting this lab.

Use the lessons for command explanations. This lab applies them to a different scenario and dataset. Study both the foundational and advanced lesson sections.

Environment and safety requirements

Work in a new C:\powershell\PowerShell-Device-Returns-Lab folder. Your instructor must first prepare C:\powershell with writable access. Routine lab commands do not require elevation once that access is ready. Inspect every state-changing command's source and destination before running it.

Preserve the two incoming logs. Do not delete files in this lab. If the workspace already exists, keep it and choose a new folder name with your instructor.

How to work in this lab

Follow predict → run → inspect → explain in each numbered activity. Commands shown under Run provide setup or a small starting point. Complete the tasks yourself; writing your own command is part of the activity.

After attempting each activity, open Show solution to compare your prediction, commands, results, and reflection answers. Where Run already provides commands, the reveal adds only missing task commands and explanations. Use the same session and earlier setup. If you already completed a file change, check its result instead of repeating that change from the solution.

Complete Parts 1 to 7 in order, including every activity. Advanced Activities 6.2 and 6.3 build on the earlier material and are part of the required learning and assessment.

Keep the same terminal open. Later activities reuse $labRoot, $inventory, $errorRecords, and $originalHash. If you close the terminal, preserve your previous work, choose a new root-folder name in Activity 1.1, and restart the lab. Do not rerun creation or relocation commands against completed work.
