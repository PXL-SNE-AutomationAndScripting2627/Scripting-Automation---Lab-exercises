Voorwaarden

Gebruik if, elseif, else en switch om beslissingen te nemen op basis van bestanden, services en gebruikersinvoer.

Bekijk de opdrachten →

Wat je leert

Leerdoelen

5 doelstellingen
  • Voorwaarden combineren met if, elseif en else.
  • $null correct vergelijken.
  • Test-Path gebruiken om bestanden te controleren.
  • Objecteigenschappen testen.
  • Keuzes verwerken met switch.

Voor je begint

Vereisten en veiligheid

  • Windows PowerShell 5.1 of PowerShell 7 en Visual Studio Code met de PowerShell-extensie.
  • Gebruik de cursus, je notities en Get-Help. Test iedere mogelijke tak, dus ook ontbrekende invoer en onbestaande objecten.
  • Het starten van een service vereist doorgaans beheerdersrechten. Werk alleen op een oefensysteem met een onkritieke testservice en herstel nadien de oorspronkelijke status.

GitHub Classroom

Inleveren

  1. Noteer antwoorden, testcommando's en resultaten in answers.md.
  2. Plaats OefIf1.ps1, OefIf2.ps1 en StartService.ps1 in scripts/.
  3. Test alle beslissingspaden en herstel de oorspronkelijke servicestatus.
  4. Commit en push je werk naar GitHub Classroom.
