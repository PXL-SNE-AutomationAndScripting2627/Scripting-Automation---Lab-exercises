Learning goals

5 objectives
  • Install and manage software with a package manager.
  • Inspect PowerShell version and execution policies.
  • Use Get-Help and Get-Command effectively.
  • Explore objects and methods with Get-Member.
  • Create and run simple PowerShell scripts.
