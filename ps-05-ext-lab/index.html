# Extended lab 05 — PowerShell-variabelen In deze lab onderzoek je variabelen als objecten, werk je met tekenreeksen en arrays en gebruik je variabelen in drie volledige scripts. > [!IMPORTANT] > Gebruik PowerShell-cmdlets wanneer die beschikbaar zijn. Baseer je op de cursus, je notities en de ingebouwde help. ## Leerdoelen Na deze lab kun je: - naam, waarde en datatype van een variabele verklaren; - properties en methods van objecten onderzoeken; - tekenreeksen en arrays indexeren; - cmdletresultaten in variabelen bewaren en opnieuw verwerken; - gebruikersinvoer naar het juiste datatype omzetten; - veilige bestandsnamen met een tijdstempel samenstellen; - gevoelige invoer als `SecureString` verwerken. ## Vereisten - Windows PowerShell 5.1 of PowerShell 7; - Visual Studio Code met de PowerShell-extensie; - voor de extra gebruikersopdracht: Windows PowerShell als administrator op een labsysteem. ## Inleveren via GitHub Classroom ```text answers.md scripts/ ├── Rekenen.ps1 ├── MakeBackup.ps1 └── AddUser.ps1 ``` Noteer korte antwoorden, gebruikte commando's en testresultaten in `
