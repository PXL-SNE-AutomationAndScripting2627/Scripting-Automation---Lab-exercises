Extended Lab 01 — PowerShell

Intro, help, objects and scripting in PowerShell.

Learning goals

  • Install and manage software with a package manager.
  • Inspect PowerShell version and execution policies.
  • Use Get-Help and Get-Command effectively.
  • Explore objects and methods with Get-Member.
  • Create and run simple PowerShell scripts.

Submission

  1. Complete the answers in answers.md.
  2. Store scripts in the scripts folder.
  3. Commit changes and push to the GitHub classroom repository.
