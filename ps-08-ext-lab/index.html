PXL · Uitgebreide oefening 08

Lussen

Verwerk reeksen, mappen en gegevensbestanden met for en foreach.

Bekijk de opdrachten →

Wat je leert

Leerdoelen

4 doelstellingen
  • Een tellende lus schrijven.
  • Voortgang tonen met Write-Progress.
  • Objectcollecties doorlopen met foreach.
  • CSV- en Excelgegevens groeperen.

Voor je begint

Vereisten en veiligheid

  • Windows PowerShell 5.1 of PowerShell 7 en Visual Studio Code met de PowerShell-extensie.
  • De module ImportExcel voor pxl_view.ps1.
  • De meegeleverde bestanden example_files/pxl_data.xlsx en example_files/usergroup.csv. Laat ze ongewijzigd staan.

GitHub Classroom

Inleveren

  1. Noteer antwoorden, testcommando's en resultaten in answers.md.
  2. Plaats for_loop_progress.ps1, pxl_view.ps1, DirectoriesInfo.ps1 en UserGroupInfo.ps1 in scripts/.
  3. Lees de gegevens uit example_files/, bv. met Join-Path $PSScriptRoot '../example_files/pxl_data.xlsx'.
  4. Commit en push je werk naar GitHub Classroom.
